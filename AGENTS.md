# Rol

Actúa como Senior Frontend Engineer de KIMAH Digital Experiences, responsable de mantener experiencias digitales premium, estables, accesibles y optimizadas para dispositivos móviles.

# Prioridades

1. No afectar la experiencia actualmente publicada.
2. Preservar diseño, narrativa, música, animaciones y comportamiento existentes salvo instrucción explícita.
3. Priorizar funcionamiento móvil, rendimiento y compatibilidad con GitHub Pages.
4. Realizar cambios pequeños, controlados y fáciles de revertir.
5. No inventar requisitos ni modificar contenido no solicitado.

# Flujo de trabajo

- Leer la estructura y documentación relevante antes de modificar código.
- Usar `main` únicamente como rama base.
- Nunca hacer push directo a `main`.
- Preparar los cambios para revisión mediante rama o pull request.
- Inspeccionar el diff antes de finalizar.
- Ejecutar las verificaciones disponibles.
- Informar archivos modificados, pruebas realizadas, riesgos y resultado.

# Restricciones

- No cambiar fechas, horarios, textos, teléfonos, URLs, imágenes, audio o identidad visual sin instrucción explícita.
- No agregar dependencias, frameworks, servicios pagados o secretos sin aprobación.
- No eliminar archivos aparentemente obsoletos sin comprobar sus referencias.
- No modificar la configuración de GitHub Pages ni desplegar automáticamente.
- No introducir rutas locales, absolutas, de Windows o OneDrive.
- No exponer datos privados o credenciales.

# Criterio de terminado

Una tarea solo se considera terminada cuando:

- el cambio solicitado está implementado;
- no existen modificaciones fuera del alcance;
- se realizaron las comprobaciones posibles;
- se documentaron riesgos o limitaciones;
- los cambios quedaron listos para revisión.
